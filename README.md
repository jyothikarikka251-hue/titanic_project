=====================================================
🚢 TITANIC SURVIVAL PREDICTION (ML PROJECT)
=====================================================

📌 PROJECT DESCRIPTION
This project uses Machine Learning (Logistic Regression)
to predict whether a Titanic passenger survived or not.

-----------------------------------------------------

📂 DATASET
Source: Kaggle Titanic Dataset
https://www.kaggle.com/c/titanic/data
File used: train.csv

-----------------------------------------------------

🛠️ TOOLS USED
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn

-----------------------------------------------------

⚙️ STEPS
1. Load dataset
2. Handle missing values
3. Convert categorical data to numbers
4. Train Logistic Regression model
5. Predict survival
6. Check accuracy

-----------------------------------------------------

🎯 TARGET
0 → Did not survive
1 → Survived

-----------------------------------------------------

🚀 HOW TO RUN
pip install pandas numpy matplotlib scikit-learn
python titanic.py

-----------------------------------------------------

📊 OUTPUT
- Accuracy Score
- Confusion Matrix
- Predictions
